# Get the warehouse cart back to its dock

We moved the cart by hand after a stoppage. It no longer knows where it is, and on the last return trip it stopped before reaching its dock.

Write a controller that returns the cart to its assigned dock using the survey map and onboard sensors. It must park at the specified pose without hitting anything. The simulator README has the interface, limits, and practice commands.

Submit `/app/policy.py` using the Python standard library and the supplied simulator client.
