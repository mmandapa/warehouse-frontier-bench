# Get the warehouse cart back to its dock

We moved the cart by hand after a stoppage, and it lost its position. On one return trip it got to a connecting aisle and found a pallet where the survey showed a clear lane. It stopped there even though another route to the dock was open.

Write a controller that returns the cart to its assigned dock from the survey and onboard sensors. Temporary obstructions can block more than one aisle, but the dock is reachable in every mission. Park at the specified pose without contact. The simulator README describes the interface and limits, and includes practice commands.

Submit `/app/policy.py` using the Python standard library and the supplied simulator client.
