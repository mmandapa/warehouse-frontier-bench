# Get the warehouse cart back to its dock

We moved the cart by hand after a stoppage. It no longer knows which aisle it is in. When we tried to send it back, it either headed down the wrong aisle or stopped short of the charging dock.

Write a controller that parks the cart at its assigned dock using the survey map and the sensors on the cart. The cart must settle at the specified pose without hitting a wall, shelf, or temporary obstruction. The README describes the simulator, sensors, and acceptance limits. You can run the included practice missions locally.

Submit a Python program at `/app/policy.py`. It must run offline using Python's standard library and the supplied simulator client.
