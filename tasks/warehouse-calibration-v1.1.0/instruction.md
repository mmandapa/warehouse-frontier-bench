# Calibrate a serviced warehouse cart

We serviced the cart and need to predict how it will move before
sending it back onto the floor. Its response can change during a run,
even when we send the same command. Use the maintenance bay to
calibrate the cart and predict its final pose for each supplied
command sequence.

Write `/app/policy.py` using Python's standard library and the supplied
client. The workspace README describes the simulator, measurement
budget, submission protocol, and tolerances.
